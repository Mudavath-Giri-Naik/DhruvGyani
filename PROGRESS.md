## Phase 1: Foundation
- Scaffolded Next.js 16, Tailwind v4, shadcn (`radix-nova`), and community components from Aceternity, Magic UI and animate-ui.
- Polar Aurora design tokens for light, dark and high-contrast; text-size control; Inter and Noto Sans Devanagari fonts.
- next-intl with a cookie-based locale (EN and HI) and full message catalogues.
- Supabase SSR clients (browser, server, admin, proxy), `src/proxy.ts` guarding `/studio` and `/admin`, Google OAuth callback, and sign-out.
- Migrations: enums, 22 tables, FTS triggers, HNSW index, role helpers, new-user trigger, role-escalation guard, approval gate, `search_items()` (RRF hybrid search), `match_chunks()`, RLS on every table, storage buckets and policies, and a Realtime publication.
- Seed module (single source) generates `supabase/seed.sql` and `all.sql`. Scripts: `db:migrate`, `db:seed`, `seed:admin`, `seed:sql`, `sql:bundle`.
- In-memory demo store with demo personas, so everything works with no keys.
- App shell: collapsible icon sidebar with role-aware groups, org switcher, live Review Queue badge, footer display controls, user menu (with a demo role switcher), breadcrumbs, a ⌘K command palette with live item search, and notifications.
- Landing page (aurora hero, Ask bar, live counters, featured expedition, feature grid, latest-items marquee, stations band) and portal home.
- Core logic with tests: numbers-and-dates check, chunker, CSV profiler, JSON retry, AI policy, RRF, and claim splitting/verdicts.

## Phase 2: Library & Search
- `/expeditions`: grid or timeline, region tabs, animated layout.
- `/expeditions/[code]` Story Mode: scroll progress bar, hero, summary with per-type counts, animated journey timeline, station band, highlights from reviewed stories, per-type archive tabs, and share (Web Share or copy).
- `/library/[type]`: filter, expedition filter, sort, and grid or table view (the table becomes cards on mobile).
- `/items/[id]`: PDF viewer, photo figure with alt text, video placeholder with transcript, Data Quick-Look for datasets, text or transcript with page numbers, glossary hover cards, a 3-level explainer (EN/HI, cited, cached), related items, plain and BibTeX citation export, favourites, and a staff panel for status, visibility and embargo (reviewers publish; newly released items get queued for embedding).
- `/explore`: debounced hybrid search, type toggles, expedition/station/year/discipline/language filters, highlighted snippets, and an "Explain simply" button. Every search, including ones with no results, is logged without personal data.
- `/studio/upload`: required release question, drag-and-drop or link, `/api/ingest/analyze` (magic-byte validation, PDF text, CSV profile, EXIF date, suggested expedition, client-side dHash duplicate check, and AI autofill **only if cleared**, otherwise offline heuristics), confirm metadata, then `/api/ingest` (private storage, item, job, `after()` processing). Also bulk CSV import with row-level validation preview, and a live jobs panel with retry.
- Ingestion jobs: PDF (unpdf, per page), chunking, embeddings (AI-gated); CSV profile and data card; photo caption and alt text; re-embed. Scanned PDFs degrade gracefully.
- `/api/files`: access-checked file serving (signed URLs in Supabase mode).
- Sample PDFs (every page stamped "SAMPLE - not real data") and synthetic CSVs generated by `npm run make:sample-pdfs`.
